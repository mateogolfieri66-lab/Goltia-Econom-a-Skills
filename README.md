# Goltia Economía Skills

Skills gratuitas de código abierto para Claude, de economía y evaluación de
proyectos. Hechas por [Mateo Golfieri](https://instagram.com/Lic.mateogolfieri) — Lic. en Economía Empresarial, fundador de Goltia.

## Disclaimer

Este repositorio es para fines educativos. Son modelos financieros
estándar (VAN, TIR, punto de equilibrio) — no son recomendación de
inversión ni asesoramiento financiero sobre ningún activo o negocio real.
Los resultados dependen enteramente de los supuestos que ingresa el
usuario (tasa de descuento, flujos de fondos, costos).

## Skills incluidas (no requieren API key)

1. **van-tir-calculator** — Valor Actual Neto y Tasa Interna de Retorno de
   un flujo de fondos, con lectura de aceptar/rechazar contra una tasa de
   descuento.
2. **punto-equilibrio** — unidades y facturación necesarias para cubrir
   costos fijos y variables, más margen de seguridad.

## Instalación

Subí la carpeta de cada skill (o el link de este repo) a tu cuenta de
Claude, o pegá el link del repo en una conversación para que Claude las
instale automáticamente.
